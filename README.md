# 🎓 College Lost & Found

A simple and colorful web app to help students report and find lost items on campus.

Live Link: Coming soon

### ✨ Features
- Report Lost Items
- Report Found Items
- Search items by category
- Colorful and student-friendly UI
- Saves data in JSON

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: JSON file
